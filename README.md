# Rudamoon AI — Gmail Assistant PWA

This PWA uses the official n8n Chat widget and connects it to the published n8n Chat Trigger.

## Files
- index.html — app interface
- manifest.json — PWA install metadata
- service-worker.js — offline shell caching
- icon.svg — app icon

## Deploy
Upload these files to any HTTPS static host such as GitHub Pages, Netlify, or Vercel.
Then open the HTTPS URL on Android Chrome and choose "Install app" / "Add to Home screen".

The n8n workflow must remain published.
